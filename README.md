# Algorithm Exercises

This directory contains zero-dependency Python implementations and written
analysis for the included algorithm exercises. The implementation uses only
the Python standard library. It records operation counts rather than execution
time so that the evidence is repeatable.

The written solution is in `ANALYSIS.md`.

## Requirements

- Python 3.
- No packages to install.
- Run every command below from the repository root: this directory, which
  contains `README.md` and the exercise files.

## Run each exercise

Each command executes only the selected exercise and prints its deterministic
evidence.

| Exercise                             | Command                                             |
| ------------------------------------ | --------------------------------------------------- |
| 5 — Largest unique value             | `python3 exercise_05_largest_unique_value.py`       |
| 6 — Chessboard grains                | `python3 exercise_06_chessboard_grains.py`          |
| 8 — Cocktail Sort                    | `python3 exercise_08_cocktail_sort.py`              |
| 9 — Numeric Bubble Sort              | `python3 exercise_09_numeric_bubble_sort.py`        |
| 10 — String Bubble Sort              | `python3 exercise_10_string_bubble_sort.py`         |
| 11 — Basic Bubble Sort metrics       | `python3 exercise_11_bubble_sort_metrics.py`        |
| 12 — Optimized Bubble Sort metrics   | `python3 exercise_12_optimized_bubble_sort.py`      |
| 13 — Search-strategy comparison      | `python3 exercise_13_search_strategy_comparison.py` |
